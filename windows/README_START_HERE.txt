Mahjong Strategy AI - Windows OFFLINE CANDIDATE

This package must pass the clean-Windows acceptance checklist before distribution.
1. Extract All into a writable local folder. Do not run inside the ZIP.
2. Double-click Start Mahjong.bat. Wait for real model/database readiness.
3. The default browser opens. If not, open the printed localhost URL.
4. Use Stop Mahjong.bat or Ctrl+C in the launcher to stop cleanly.

Normal operation uses bundled Python/PostgreSQL/model/assets, no Docker/Node/pip
or internet download. Optional Swagger/ReDoc UI may require its documentation CDN.
History/private configuration live under LOCALAPPDATA\MahjongStrategyAI, not the
read-only package; retain that folder and browser cookie across restarts.
Active games are in memory and do not survive application restart.

The package is unsigned. Do not disable antivirus/SmartScreen or bypass policy.
If blocked, contact the owner for a validated/signed build. Missing DLL, architecture,
port collision, invalid model, failed readiness or incomplete extraction is a real
failure; inspect private diagnostics.txt. Never share state.json or passwords.
No unrelated process/service is killed. Existing data is never silently replaced.

Readable Python source: source\. Actual templates/CSS/JS/tile art:
app-runtime\_internal\app\. Licenses/provenance and checksums accompany the build.
